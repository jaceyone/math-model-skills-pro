# G1 建模门禁（含三轮回质检）

## 一、报告内容完整性（第 1 轮看的）

- [ ] 子问题数量与题面一致
- [ ] 每个子问题有输入/已知条件
- [ ] 每个子问题有决策变量/预测对象/评价对象
- [ ] 每个子问题有目标函数或评价指标
- [ ] 每个子问题有约束条件
- [ ] 每个子问题有求解方法与停止条件（含复杂度或可行性说明）
- [ ] 每个子问题有输入输出与代码实现要点
- [ ] 每个子问题有结果校验方法（可机器执行：解析对照 / 守恒 / 极端情形 / 交叉验证，至少一种）
- [ ] 每个子问题有 3–6 条可核验得分点（用原词，不写态度描述）
- [ ] 每个子问题有证据链表（得分点 → 交付物 → 落点章节 → 验证方式）
- [ ] 每条 claim 写成「对象 + 方向」且判定口径明确；含「优于/显著/最优」的已规划 ≥2 类互补检验
- [ ] 预测类问题已建朴素/统计基线，未预设深度模型
- [ ] 假设敏感性预检已完成
- [ ] 数据理解（缺失/异常/单位）已写
- [ ] 图件规划覆盖四路（数据/机理/主图/流程），数据图张数与角色已定
- [ ] 代码任务清单已写
- [ ] 术语表格已写
- [ ] 符号表已写（`reports/symbols.md`）：一符一义、含单位、按首次出现排序，且与 S2 代码变量名一一对应；S4 的「符号说明 / Notation」章直接照抄，不重排、不改名
- [ ] 没有编造数据字段或数值

## 二、三轮回质检（缺一轮不算过）

留痕文件：`reports/QC_S1_ROUND.1.md`、`reports/QC_S1_ROUND.2.md`、`reports/QC_S1_ROUND.3.md`，
每份格式 `| # | 轮次 | 位置 | 问题 | 严重度 | 改法 | 状态 |`，末尾一行 `结论：PASS` 或 `结论：FAIL`。

| 轮次 | 检查维度 | 通过判据 |
|---|---|---|
| 第 1 轮 | **结构与覆盖**：上面的完整性清单 + 得分点可核验性 + 图件四路不混 | 缺项 0；每个得分点都能指向一个数值/图/表 |
| 第 2 轮 | **一致性与冲突**：符号表 ↔ 公式 ↔ 图件规划 ↔ 代码任务清单 同一套符号；假设之间不打架；初值/边界条件写全；**通篇没有"二选一"式表述**（"或者 A 或者 B"必须落成一条判据） | 符号零冲突；每条假设都能在模型里找到落点；模糊表述 0 处 |
| 第 3 轮 | **可执行性与校验**：每个公式参数给全、量纲一致；每问有可机器执行的校验；灵敏度方案写清自变量、取值、判据 | 参数与单位齐全；每问 ≥1 条可执行校验；灵敏度自变量明确 |

规则：

- 三份留痕的结论行都必须是 `结论：PASS`。
- 任一轮 `FAIL` → 回报告改 → 从**该轮**重跑（不要求重跑第 1 轮）。
- 质检期间只改 `reports/*.md`，**不许动 `code/`**；发现必须改模型时，先改报告与 `symbols.md`，再继续。

## 三、通过条件

- [ ] 上面两节全过
- [ ] `reports/ANALYSIS_MODELING_REPORT.md` 已落盘，且能独立复现（别人只看它就能写代码）

通过后进入 S2。**未过 G1 就写模型代码或出数据图 = 流程违规**，S4 一定会出现模型与结果两张皮。
