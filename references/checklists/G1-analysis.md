# G1 建模门禁

- [ ] 子问题数量与题面一致
- [ ] 每个子问题有输入/已知条件
- [ ] 每个子问题有决策变量/预测对象/评价对象
- [ ] 每个子问题有目标函数或评价指标
- [ ] 每个子问题有约束条件
- [ ] 每个子问题有求解方法与停止条件
- [ ] 每个子问题有输入输出与代码实现要点
- [ ] 每个子问题有结果校验方法
- [ ] 每个子问题有 3–6 条可核验得分点（用原词，不写态度描述）
- [ ] 每个子问题有证据链表（得分点 → 交付物 → 落点章节 → 验证方式）
- [ ] 每条 claim 写成「对象 + 方向」且判定口径明确；含「优于/显著/最优」的已规划 ≥2 类互补检验
- [ ] 预测类问题已建朴素/统计基线，未预设深度模型
- [ ] 假设敏感性预检已完成
- [ ] 数据理解（缺失/异常/单位）已写
- [ ] 图件规划覆盖四路（数据/机理/主图/流程），数据图张数与角色已定
- [ ] 代码任务清单已写
- [ ] 术语表格已写
- [ ] 符号表已写（`reports/symbols.md`）：一符一义、含单位、按首次出现排序，且与 S2 代码变量名一一对应；S4 的「符号说明 / Notation」章直接照抄，不重排、不改名
- [ ] 没有编造数据字段或数值

通过后进入 S2。
