# 13 · 写作注入规则（摘要 / 建模推导 / 一致性 / 统计 / 引用）

> 本文件只管「写成什么样才得分」：摘要句链、推导三段式、一致性、表格、统计、引用六类注入规则。
> **与 `10-chapter-writing-prompts.md` 的分工**：`10` 管「这一章怎么排、写什么」，本文件管「写成什么样才得分」——版式冲突时以 `10` 与模板 `.tex` 为准，判分标准以本文件为准。

## 一、摘要（国赛硬约束）

在模板 `0.摘要.tex` 的开头段 / 逐问段 / 结尾段 / 关键词版式之上，再加：

1. **每问句链**：「针对问题N，考虑〈关键因素〉，将其转化为〈问题类型〉，建立〈模型全名〉，采用〈算法〉求解。结果表明，〈2–4 个带单位定量结果，含相对基准的改进幅度〉」。句式长短要有变化，不逐字排比。
2. **模型必须有正式全名**，并与该章标题同名；只写「遗传算法」这类裸名失分；禁止连字符串名（「预测-检验-机制」）。
3. **踩得分点**：段内覆盖该问得分点的可核验交付（用原词），但**只写有利结论**；局限、违反量、权衡失败放「模型评价」，摘要里禁止元叙述。
4. **数值纪律**：统一 3–4 位有效数字；上万的量换万/亿（5172612.80 元 → 「约 517 万元」）；占比/概率/相对误差写百分数（0.9991 → 99.91%，概率 1 → 「≈100%」），不留裸小数。
5. **量级常识校核**：每个数换成日常单位念一遍再写。「平均候车 375.76 min」是六个多小时，这类必是口径错（累计量当均值、罚金淹没成本），回查结果，不许照抄。确认无误的反常值（如负成本）用半句有利口径（「净收益」）。
6. **同名同口径**：「运营成本」与「含惩罚总成本」不得都简称「成本」相邻比较；跨问引用同一基准时同一指标必须同值。推荐方案 ≠ 最优解/膝点时，半句话说清为什么改选。
7. **确实做不到时**：不自陈失败。点名卡在哪个约束及临界值 → 退一步方案的定量表现 → 要达标需放宽到什么程度；「代价 0 元、0%」这类空话删掉。
8. **关键词 4–6 个**：方法名与场景词兼有（≥2 个场景词），无公式、无图、无角标。
9. **一页铁律**：连标题与关键词必须写满首页、且不得溢出到第二页。留白与溢页都是硬伤，靠补齐定量结果写满，不注水。

## 二、建模推导（评委要看见「建模」，不只看思路和结果）

1. **三段式**（`5.X.3 模型建立`）：
   ① **形式化**：集合/下标/参数/决策变量，带取值范围与量纲；
   ② **机理推导**：从假设逐步推到核心方程，守恒/几何/统计关系写清，**不许跳步**；
   ③ **完整模型陈述**：目标函数 + 全部约束集中呈现一次。
   禁止从假设直接跳到最终公式。分点用加粗正文 `**（1）决策变量**`，不要靠深层标题撑结构。
2. **公式分类与密度**：本章公式至少覆盖 4 类 —— 定义式 / 目标函数 / 约束 / 求解或更新式 / 检验或评价指标，只堆一类不算数。模板给的「每步 ≥6 个公式」是**下限不是目标**，讲透就停。
3. **一条编号式 = 一个独立建模决策**：同一步骤的代入/化简/整理不各编一次号，中间过渡用行内式或文字带过；也不要把三四条关系用 `\quad` 塞进一个公式块凑数（符号墙）。
4. **编号优先给自建式**：本题自建的定义/目标/约束/求解式写透；教科书翻开就有的通用式（RMSE/R²、相关系数、z-score、softmax、香农熵、PCA、TOPSIS 等）**每章最多编号 2 条**，其余行内点名并给出处。
5. **辅助论证下沉**：引理/命题的完整证明、逐步代数化简、次要假设的合理性讨论放章末补充材料或附录，正文只留结论式 + 一句依据 + 「详细推导见附录」。
6. **公式必解释**：每个核心公式后另起一行「其中，$x$ 为……（单位）」；符号先定义后使用、一符一义；等号两边与加减项**量纲一致**。
7. **算法块**：算法/优化求解类（规划/优化/调度/排样/路径/图论/启发式/迭代/仿真）**必须**给算法块，步骤里看得见**初始化 / 主循环 / 终止条件 / 输出**四环节，带复杂度与对应函数名；正文用「算法 N」引用并解释关键步骤为何这么设计。伪代码写逻辑，不贴源码、不出现库调用细节。数据驱动类（特征筛选/回归预测/分类评价）不强制算法块，但关键训练/筛选/调参流程要步骤化写清，不能只说「用随机森林筛选」。
8. **机理示意图**：每问至少一张机理图解释「为什么这么建模」，走本技能路线② `tools/mechanism-diagram`（TikZ），**不得用 matplotlib 手绘模块框图冒充**；图上符号与公式同名同义，正文插入后一两句对到公式。技术路线图 / 机理图 / 伪代码三者互不替代。
9. **选型论证由数据与假设驱动**：不写「该方法效果好」「非它不可」，要回答 ① 哪些数据/结构特征支持它（含核心方程形式的取舍：线性 vs 非线性、静态 vs 动态、参数化 vs 非参数）；② 至少 1–2 个合理替代在同一口径下的取舍；③ 样本量、可解释性、计算代价是否匹配；④ 关键假设是否经诊断成立。不预设某个模型必然高级；若声称「优于/显著/推荐」，文字论证不能替代公平基线或统计验证。关键超参数集中成表并写明取值依据。
10. **合理性验证独立成节**：单开「模型的检验与合理性验证」，不是复述结论而是自证 —— ① 内部一致性各一句结论 + 一个数；② 对照/消融**真跑了才写**，比较放「结果与分析」的一张图或一张多指标三线表，检验节只点「见表/图 X.Y，指标由 A→B」；③ 指出局限。全部取自真实结果，没跑不造稻草人基线。
11. **末尾回扣各问**：最后一问或结论前用一小节说明各问结果的一致性（同类变量反复出现、结论互相印证），这是整篇可信度的收口。
12. **严谨性（按 SCI 标准）**：
    - **假设要兑现**：每条假设都在推导中点名用到（「由假设 3，……故可拆成加性项」）；列了从不引用的假设等于没写，删掉。
    - **近似要交代代价**：线性化/离散化/稳态近似/分布假设/独立性假设，必须写明【适用条件 + 误差量级或方向 + 什么工况下失效】，不许只说「为简化计算」。
    - **性质要给条件**：声称收敛/稳定/唯一/有界/最优，写明成立条件与判据；给不出就改写成「数值上观察到」。最优化说清精确最优还是启发式，并报 gap。
    - **禁空转句**：「具有重要意义」「众所周知」「由此可得」（不给依据）「该模型科学合理」「充分体现了……」一律不写。
    - 公式里的数值参数与 `results.json`、代码常量一致。

## 三、写作一致性

1. **一级标题连续编号**：问题重述 → 分析 → 假设 → 符号 → 建立与求解 → 检验与灵敏度 → 评价改进 → 参考文献；附录不参与一级编号。章内真正进目录的只用二、三级；「（1）（2）…」写加粗正文，不用四级标题。
2. **摘要**按第一节 + 模板版式；须含 ≥3 个来自 `results.json` 的规范显示值；与灵敏度章结论一致。
3. **图必须被正文引用并解读**：优先依据 `reports/journal_problemN.md` 的图表结论落笔；数字与 `results.json` 一致；全文实验预算只有一套。
4. **灵敏度必须真实重跑**：密采样响应曲线用图，离散扰动改数值三线表，一两条写成句子；均配文字结论，禁「模型稳健」空话。
5. **禁编造文献**：无法核实写「待核实」占位；正文角标与文末条目一一对应。
6. **配置声明与代码一致**；结论强度不超证据；直接输出正文，禁止过程旁白（「下面我来写…」）。
7. **人类化行文（漂亮 ≠ 空话）**：句式长短交错；少用机械「首先/其次/最后」；分析处写清数据背后的直觉与权衡；用具体数字替代「显著/大量」；能段落叙述就不堆列表；润色不得改动数值。
8. **算法块与图二选一**：同一套求解步骤不得算法块与技术路线图各来一遍。
9. **符号写法**：正文与符号表里的量一律行内公式 —— LaTeX 用 `$\\theta_i$`、`$\\Delta t_{\\text{drop},k}$`；Word 用斜体 Times/Cambria Math 插入。**禁止 `θ_i`、`Δt_drop_k` 这类纯文本下划线写法**（下划线会原样印出来）。
10. **表题在上、图题在下**；题注必须具体 —— 写清画的是哪些量、在对照什么，不看正文也知道里面有什么（「图 3.3 各预测步长下混合模型与纯 GRU 的 RMSE 对比」），禁用「结果图/对比图/示意图/效果图/问题N结果图」这类看不出内容的题注，也不要只写方法名不写被观测量。题注里的变量名与正文、符号表一致，有单位就带上。
11. **模型假设**：5–8 条，逐条编号，每条一句话 ≤60 字，格式「**假设名**：口径」；全节约半页，不给每条再补「理由：…」的论证段。
12. **参考文献**：GB/T 7714 著录，一条一行、行首 `[n]` 连续编号，不把多条挤进一段。
13. **篇幅与赛制口径**：国赛 28–30 页（含摘要、参考文献、附录）；华为杯 50+；美赛总页数上限 25 页（含 Summary Sheet、目录、参考文献、附录，AI 使用报告附录按当届规则通常不计页）；亚太约 22 页。美赛另需独立一页 Summary Sheet（方法亮点 + 关键结论 + 创新点，不是正文摘要的复制），全文英文。删套话与背景铺垫，同一结论只讲一次；逐次运行明细、参数网格全表、次要对照进附录。当届官方规则与本节冲突时以官方为准。

## 四、表格：有数才成表

- 表不限张数、不限行列，需要横向对照数据的地方就放；唯一硬条件是**表里得有数**（实测值/指标/取值/变化幅度）。整片是词组的「方法优缺点/适用条件/流程说明/要点罗列」表读不出任何量，一律写成正文一句话（符号总表除外，它是索引）。
- **单元格只放数字、单位、符号与 ≤8 字短语**：禁止在格子里写整句、写理由、写公式推导；「说明/依据/物理意义」这类长文本列删掉，改到表下一句话点评。
- 整列同值（全是「—」「默认」）或能由别列推出的列删掉，表下一句话交代。
- 同列小数位统一，别照抄 `0.18039094834580585`；百分比与绝对值不混排在同一列。
- 逐点预测值、逐日明细、参数扫描全表进附录，正文留汇总行；章内重复的符号小表不写。
- 表下正文不要把表里的数字再念一遍，只点最值、拐点或差距最大的那一项。
- **对照/消融**：一张图或一张表并排各方法，正文一句点差距；不要图、表、长文同时讲同一组对比。

## 五、统计分析

1. 先检验假设（正态性/方差齐性/独立性），再选检验；报告效应量与置信区间，不只报 p 值。
2. 多重比较须校正（FDR / Bonferroni）；结果表述统一风格。
3. 图表标注显著性；数值来自 `results.json`，禁止编造 p 值。
4. 样本量与重复次数在正文交代（「30 次独立重复，种子 42–71」）。

## 六、科学写作与引用

1. 中文论文按 IMRAD 组织；相关工作/背景独立成章，不塞进实验任务章。
2. 引言用漏斗：背景意义 → 问题提出 → 现有局限简述 → 本文贡献（须与创新点一致）。
3. 相关工作按主题脉络分类，每脉络 ≥2–3 篇代表文献并说明思路与局限，禁止罗列体；结尾指出空白并与方案 gap 呼应。
4. **实验设置单一事实源**：种群/批量规模、迭代次数、独立运行次数、样本量、种子、数据集划分，全文只有一套，以 `results.json` 为准；摘要、方法、实验、结论中这些数字逐字相同。`results` 里没有的数字不写具体值。
5. **配置声明一致**：摘要/结论宣称的最终配置（是否含修复算子、补偿、正则等模块）必须与方法章与代码一致，禁止一处「未使用」另一处「最终选用」。
6. **跨表一致**：同一算法同一设置的指标/运行时间在所有表格与正文中相同；确属不同批次须在表题与正文注明差异。
7. **统计口径一致**：检验重复次数、显著性水平、多重比较校正方法全篇统一且与结果文件一致；不显著就写不显著。
8. **引用管理**：中文 GB/T 7714；正文角标与文末条目一一对应，不得「有引用无条目」或「有条目未引用」；缺失字段标「待核实」，禁止编造 DOI/作者/年份；每条引用必须由 `tools/paper-search` 返回且可校验。

## 七、语言规范与去 AI 味

> 口径参考开源项目 `XiaoMaColtAI/math-modeling-skill` 的《论文手说明》「去 AI 味写作指南」，落到本技能即模板 `main.tex` 顶部 `% 【全文语言规范与去 AI 味】` 注释块（写哪章过一遍，终稿再过一遍）。

1. **人称**：不用「本研究 / 本论文 / 笔者 / 我们 / 我」，统一「本文」或省略主语。「该模型」优于「我们提出的模型」。
2. **断句**：整段叙述，每段 3–5 句；分点只允许出现在模型假设、符号表、算法步骤（3–5 步）、优缺点、附件说明表。
3. **AI 高频词**：此外、另外、关键的、核心的、深入探讨、具有重要意义、为…奠定基础、体现了、充分展示了、标志着、不断发展的格局 → 换成具体动作与数值。
4. **禁套式**：「不仅…而且…」否定平行；强行三连（准确、快速、稳定）；虚假的「从 X 到 Y」范围；公式化「挑战与展望」；通用积极结论（前景光明、意义重大）。
5. **禁排版腔**：破折号每页 ≤1 处；正文加粗只给模板位（`\textbf{假设N：}`）；不用 emoji、不用「**小标题：** 内容」式内联列表。
6. **去填充与模糊**：「值得注意的是 / 事实上 / 在此时此刻 / 具有一定的 / 某种程度上 / 可能可以认为」删除；「专家认为 / 研究表明」必须落到具体文献。
7. **具体与节奏**：每个结论跟数据、单位或条件（「50 城规模、100 代内收敛、路径长 1234.5 km」）；长短句交替，不写同构同长的排比段。
8. **承认局限**：写清代价（时间 / 精度 / 适用规模），不写「性能优越、结论可靠」这类空话。
9. **终稿自查 10 条**：AI 词残留 / 破折号粗体 emoji 过多 / 否定平行 / 强行三连 / 模糊归因 / 公式化展望 / 空泛结论 / 每句有支撑 / 句长有变化 / 写了局限。
