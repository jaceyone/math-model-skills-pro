## 使用规则

1. 只读当前阶段需要的 1–2 个文件；`10`–`14` 是**现场口径**，优先于 `01`–`06` 的通用建议。
2. 先读标题和表格，再读对应小节。
3. 知识库给的是判断依据，不替代题目与数据。
4. 与当届官方规则冲突时，以官方规则为准；与模板 `.tex` 末尾提示词冲突时，以模板为准。
5. 不把知识库内容整段抄进论文。

## 内容范围

- `01`–`06`：题面拆解、模型选型、题型防错、代码与结果、图种选择、验收六类通用方法，按主题拆分。
- `10`：本技能现役写作口径库（18 节：总纲 + 摘要到附录 12 节 + 问题一 5 小节）；与 `default/sections` 的映射见 `stages/04-writing.md` §2。
- `11`–`14`：执行纪律、得分点与验证、写作注入、绘图契约四类硬约束；`14` 的 API 表对应 `assets/style/plot_style.py`。
