## 一、选版式（先读表，再开图核对一眼）

| id | 一句话结构 | 用它的题 | 别用它 |
|---|---|---|---|
| `grouped-tasks` | 输入 → 3–4 个任务组横排 → 目标 | 任务 3–4 个，有明确输入与输出物 | 只有 2 个任务 → `staged-steps` |
| `nested-cluster` | 上位主题框住 4 张任务卡 | 有总主题（可持续性 / 气候缓解 / 韧性） | 任务互不相干、找不到上位主题 |
| `quad-matrix` | 2×2 任务组 + 方法椭圆 + 竖排指标条 | 4 个并列任务，任务间有方法调用 | 任务间没有结果传递 |
| `multi-panel` | 5 块不同底色面板各讲一件事 | 一张图同时交代流程 + 方法 + 结构 | 一句话能讲清时；密度最高也最易花 |
| `staged-steps` | 步骤 1–5 底色底板串联成回路 | 分阶段方法链（评估→优化→协议→扩展→落地） | 步骤少于 3 |

## 二、骨架（复刻按这个排，不按感觉排）

### 01 `grouped-tasks` · 任务分组横排

**结构**：`给定数据 + 团队 → 任务1 网络分析 → 任务2 绩效指标 → 任务3 组建与训练 → 目标与行动`，任务4 箭步挂在任务3 下方。
**布局**：两端浅蓝实心块（输入 / 输出），中间三块等宽深蓝虚线圆角框，框左上写组名，框内纵向 3–5 个节点，关键两步用深蓝虚线小框圈住；跨组用块状大箭头，数据文件名只写一次（贴底）。
**要点**：① 三组等宽、间距一致；② 每组超 5 个节点就拆组；③ 组内箭头细直线 + 实心三角，跨组才用块状箭头。

### 02 `nested-cluster` · 总分嵌套

**结构**：`上位主题框 ⊃［任务1 指标块 + 任务4 因果块］/［任务2 影响块 + 任务3 时间·空间块］`。
**布局**：最外层大圆角虚线框，顶部居中写主题（可持续性 / 气候缓解）；内部上排两块、下排两块，各自再用虚线 / 点划线区分主次；任务4 是「两因 → 一国 → 两出口」的三角因果，任务3 是「趋势 ←→ 优劣势 ←→ 博弈」的双向链。
**要点**：① 至少三种线型（外框实线圆角、任务框虚线、子块点划线）才能读出层级；② 每块底色不同但同饱和度；③ 主题词单独一行，不塞进任务框。

### 03 `quad-matrix` · 2×2 任务矩阵

**结构**：`竖排指标（社会/生态/交通/能源）→ 指标识别 → FWM → 多层因子指标 ‖ K-Means → 四类社区应用`；`三种策略 → 影响水平预测 → 平均情况 / 理想愿景`⇄`策略 → 效果分析`。
**布局**：左上任务1（4 条竖排浅黄细条 + 2 个亮绿圆角块 + 居中灰椭圆 FWM）；右上任务2（灰椭圆 K-Means + 右侧 4 个浅粉块扇形分叉）；右下任务3（2 个绿块 + 2 个浅蓝并列块）；左下任务4（1 个绿块 + 2 个浅蓝块 + 两条细箭头，箭头旁写「能源策略 / 城市规划策略」）；任务3 与任务4 之间用块状箭头反向连。
**要点**：① 四个「任务N」角标统一压在框左上、字号相同；② 方法名只进灰椭圆，不写进正文句；③ 竖排条只给并列指标，不给流程节点。

### 04 `multi-panel` · 多面板拼合

**结构**：五块不同底色虚线面板并排 —— 纵向流程（模型 + 自我反馈环）/ 公式 + 回归与箱线分析 / 数据特征 / 内嵌随机森林与网格搜索的流程 / K-Means 分层结构。
**布局**：左面板竖排四段（输入→模型→输出→预测），模型两侧画自环箭头；中面板上方放公式 `score = w₀Σ + w₁p₁ + w₂p₂`，左侧回到两列小框（回归 / 箱线），箭头汇入下方流程；右上面板两块深色结论块；右下面板画层叠薄片表示分层。
**要点**：① 每块面板必须有独立信息，删任意一块讲不通才算合格；② 弃用分支标红 ✗；③ 面板底色与节点色同族，最多 5 种。

### 05 `staged-steps` · 分步串联

**结构**：`步骤1 评估 → 步骤2 优化 → 提案`；下排 `步骤4 扩展 / 步骤3 协议 / 步骤5 一页信函` 串成回路。
**布局**：步骤1 浅青底板，三行小框（指标→人员/技术/过程→方法 FESM、EWM-AHP→成熟度水平），方法名写在白底黑边方框里；步骤2 右侧大底板，三个胶囊 + 空白坐标轴示意（x/y/z 三轴）；下三块底板用块状箭头串起来。
**要点**：① 步骤名写在底板左上「步骤N：动词」；② 胶囊只给并列要素，白底黑边方框给「产出物」；③ 坐标轴示意只画轴与变量名，不画数据。

## 三、通用视觉规范（唯一来源；`tools/paper-figure/SKILL.md` 只引用本节）

| 元素 | 做法 |
|---|---|
| 组框 | 虚线圆角框（`dash 7-5`）或点划线（`dash 1-4`），低饱和底色；上位主题再包一层更大的圆角虚线框 |
| 角标 | 组框左上角压边的深蓝实心圆角块（#1F4E79 白字，写「任务1 / 步骤2」），或加粗写在框内左上角 |
| 节点 | 圆角矩形（rx 8–14）+ 同族描边；关键步骤改胶囊（rx = h/2）；常规流程节点可白底黑边 |
| 竖排条 | 并列指标写成竖排细条块（社会 / 生态 / 交通 / 能源），一条一项 |
| 方法标注 | 灰底椭圆（FWM / K-Means）直接压在流程线上 |
| 箭头 | 细黑直线 + 实心三角；跨组推进用块状大箭头；箭头旁写约束词（时间 / 空间 / 能源策略） |
| 弃用分支 | 红 ✗ 标在线上 |
| 配色 | 亮绿 #92D051 · 淡绿 #ADC9A4 · 亮黄 #FFD966 · 浅黄 #FDEBB5 · 天蓝 #A4BAE0 · 浅蓝 #CCDFEA · 粉 #F8CCB0 · 淡紫 #DAC3DE · 青 #A8C6C9 · 深蓝 #1F4E79（一张图取 3–5 个） |
| 字号 | 组标题 20–22 加粗、节点 16–18、线上注释 12–14（15 cm 宽插图约 8–9 pt） |
| 文字 | 只写任务名、指标名、方法名、约束词；不加副标题、编号、页脚、说明句 |

## 四、用法

```bash
python tools/paper-figure/scripts/select_reference.py --list
python tools/paper-figure/scripts/select_reference.py --id quad-matrix --json
python tools/paper-figure/scripts/select_reference.py --id quad-matrix --copy-to refs/quad-matrix.jpg
```

再加一张母版（只入 jpg，不再生成 PNG/PDF）：

```bash
python tools/paper-figure/scripts/import_plate.py --src refs/new.jpg \
    --id three-band --title "三段并排" --pattern framework \
    --description "左中右三段各带小标题" --use "三问并列" --avoid "任务不足三段"
```
