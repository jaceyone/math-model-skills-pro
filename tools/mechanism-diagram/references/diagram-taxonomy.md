# 数学建模机理图图谱（画哪张、画什么、能标什么）

本件只管**机理示意图**：讲清"这个模型的原理是什么、几何关系在哪里、求解的逻辑怎么走"。
真实数据点、真实结果数值一律归数据图（matplotlib/Excel 那一路），不在本件范围内。

---

## 1. 先划边界：这张图该不该由本件画

| 判据 | 归本件（TikZ 机理图） | 不归本件 |
|---|---|---|
| 图里有**实测/算出来的数据点**要落坐标 | 不画 | 数据图（matplotlib） |
| 图要表达的是**几何关系/结构/原理/演化机制** | 画 | — |
| 图需要 **LaTeX 公式**跟正文同一字体系统（$\Delta f<\epsilon$、$\eta_i=1-e^{-wA/Q}$） | 画（这是 TikZ 的天花板） | — |
| 简单分层框图、纯分组树（无公式、无跨层连线） | 别用 TikZ，绝对坐标手写易翻车 | DrawIO / HTML 图 |
| 写实 3D 场景、透视立体、设备外观 | 画不了也不该画 | 渲染图 / GPT Image |
| 照片级实物（无人机、传感器、建筑） | 不画 | 图片 | 一句话：**符号与几何归 TikZ，数据与真实值归绘图库，写实与立体归图像模型。**

## 2. 模型类别对应的机理图触发表

拿到材料后逐个模型对表。命中即规划一张图，一图只讲一件事。

### 优化类（线性/整数/非线性/多目标/动态规划/路径规划）

| 图型 | 画什么 | 关键技巧 | 易翻车点 |
|---|---|---|---|
| **可行域图** | 约束直线/曲线围出的多边形（或非线性边界）+ 目标函数等高线族 + 梯度方向箭头 + 最优点落在哪个顶点/切点 | `clip`+`fill opacity` 罩可行域；`\foreach` 画平行等高线；顶点用 `\fill` 实心点 | 手写"最优点坐标 $(3.27,1.85)$"——这是解出来的结果，只能写 $(x_1^*,x_2^*)$；等高线与约束线同色分不清主次 |
| **整数规划割平面/分支示意** | 可行域 + 整点栅格 + 割线逐步收紧，或分支树与各自松弛域 | `\foreach` 画整点；dashed 表示被割掉的域 | 分支节点里塞具体目标值 |
| **路径/方案示意**（VRP、无人机航线、巡检顺序） | 题面给定的点位+背景几何（坐标系、边界、障碍物）+ 方案路径折线 + 关键角/距离符号标注 | `calc` 库算角度与投影；`decorations.markings` 沿路径放箭头 | 把点位坐标当成"算出来的结果"（若来自题面附表＝给定常量，可标；若是自己编的＝造假，不画） |
| **多目标帕累托结构示意** | 目标空间的支配关系、前沿形状、权重向量方向（**概念示意**，不落真实解点） | 手绘示意曲线 + 支配箭头 | 把真实求解点当示意点画进去，这种必须走数据图 | ### 微分方程 / 动力系统类（传染病 SI/SEIR、捕食-竞争、弹簧阻尼、热扩散、人口 Logistic）

| 图型 | 画什么 | 关键技巧 | 易翻车点 |
|---|---|---|---|
| **相平面图** | 零倾线（nullcline）+ 平衡点及其稳定性类型 + 若干条代表性相轨迹走向 | `\foreach`+`\pgfmathsetmacro` 画向量场；轨迹用 `domain/samples` 手写解析式或已知数值表 | 为了画轨迹把 `solve_ivp` 跑出来的数值点列硬敲进 tex（该走数据图；本件只画定性形状） |
| **向量场/稳定性分区** | 状态空间分区（收敛域/发散域/极限环）+ 边界流形 | 分区用 `fill opacity` 浅色，流形实线 | 用低 opacity 淡化文字 |
| **仓室/传播链示意**（SEIR 类） | 各仓室方框 + 转移箭头 + 箭头上的速率符号（$\beta S I$、$\gamma I$）+ 出生死亡进出 | `positioning` + `bend left/right` 双向箭头错开 | 同一对节点两条直箭头完全重叠 |
| **控制体/微元示意**（热传导、扩散、流体） | 取一段微元 $\mathrm{d}x$，标进/出通量、面积、厚度、坐标 | `patterns` 画材料剖面；双头箭头 `<->` 标尺寸 | 微元尺寸与通量箭头挤在同一侧 | ### 几何 / 物理机理类（遮挡与视野、覆盖宽度、光路、受力、成像、机械）

| 图型 | 画什么 | 关键技巧 | 易翻车点 |
|---|---|---|---|
| **几何推导构造图**（本件最高价值的一类） | 主图：坐标系 + 题面已知量（半径、螺距、板长、入射角）+ 关键辅助线；**分步标注中间量** $\theta_i,\ r=b\theta,\ L_i,\ \Delta\varphi_i$，把"怎么一步步推出来"画在图上 | `calc` 库做投影/旋转/定比分点（`$(A)!0.5!(B)$`）；角度用 `arc`；局部放大用 `spy` 或 inset 小图 | 把 6 个标签堆在同一个焦点上；把推导公式整段焊进图内（>2 行必须回正文） |
| **自由体受力图** | 隔离体 + 各力矢量箭头 + 角度弧 + 分解后的分量虚线 | 力箭头彩色、**力符号文字纯黑**；`patterns=north east lines` 画固定面 | 用红色写"$F=12.3\,\mathrm{N}$"这种结果值 |
| **光路系统图** | 主轴（虚线）+ 透镜/反射面 + 光线束 + 焦距与像距的双头箭头 + 成像关系符号 | `ellipse` 画透镜；光线用 `bend` 表示偏折；焦点实心点 | 光线与标注文字互相穿过；透镜填充过深盖住光线 |
| **临界/极限位置对比图** | 同一几何在两个临界状态下的叠图（如实线=临界、虚线=一般位置） | 一图两态，用 dashed 区分；状态名标在**引线端** | 两态全用实线导致分不清 | ### 评价 / 决策类（AHP、熵权、TOPSIS、模糊综合评价、灰色关联、DEA）

| 图型 | 画什么 | 关键技巧 | 易翻车点 |
|---|---|---|---|
| **指标层次结构图** | 目标层—准则层—指标层三层树 + 层间连线（表示"由谁构成"） | 层用虚线框分组；同层节点等间距 | 把各指标**权重数值**标进层次图（权重是算出来的，该进结果表或柱状图） |
| **隶属度/归一化几何示意** | 三角形/梯形隶属函数、指标值映射到 $[0,1]$ 的几何过程 | `plot` 分段函数 + 阴影表示隶属度 | 用真实评分数字当横轴刻度 |
| **贴近度几何示意**（TOPSIS 概念） | 正/负理想解点、待评方案点、欧氏距离 $D^+/D^-$ 双头箭头 | 概念点用符号 $S_i$，位置只需定性正确 | 声称"按真实坐标绘制"却又承认数据是编的 | ### 预测 / 随机过程类（回归、时间序列、灰色、马尔可夫、元胞自动机、蒙特卡洛）

| 图型 | 画什么 | 关键技巧 | 易翻车点 |
|---|---|---|---|
| **马尔可夫状态转移图** | 状态圆节点 + 带概率符号的转移箭头 + 自环 | `automata` 库；自环 `loop above`；对称转移用 `bend` 分开 | 转移概率写具体小数结果（题面给定可写，模型估计出的 $p_{ij}$ 不可写） |
| **元胞自动机邻域/演化示意** | 栅格 + 中心元胞 + 邻域高亮 + 规则表达式（如 $S\to$ 阈值） | `\foreach` 双层画栅格；`fill=主色!12` 高亮 | 把模拟输出的某一帧当"示意图"而不声明 |
| **几何概型/随机布点示意** | 样本空间几何体 + 事件区域阴影 + 概率 = 面积比的标注 | 区域 `fill opacity`；事件边界实线 | 用低 opacity 淡化文字 |
| **概念收敛/衰减曲线** | 函数形态（如 $e^{-kt}$）+ 轴刻度用**符号**（$t$、$k$）而非拟合数值 | `domain/samples` 的解析式必须是正文里那个 | 把拟合出的参数值敲进 tex 冒充解析式 | ### 机器学习 / 深度学习模型类

| 图型 | 画什么 | 关键技巧 | 易翻车点 |
|---|---|---|---|
| **模型结构机理图**（MLP/CNN/LSTM/Transformer/PINN） | 层/模块方框 + 数据流箭头 + **模块内部机制**（LSTM 三门一记忆、注意力 $\mathrm{softmax}(QK^\top/\sqrt{d})V$、CNN 感受野堆叠、PINN 的物理损失支路） | `positioning` 堆叠；残差/回环走图最外侧用 dashed；公式节点用 `$...$` | 只画"输入、模型、输出"三段空壳，等于没讲机理 |
| **训练/求解机制示意** | 前向—损失—反向的闭环 + 各支路损失的符号式 | 回路箭头走外侧空白 | 回路箭头穿过中间的损失节点 |
| **算法流程图（带公式与分支）** | 判断菱形 + 分支"是/否" + 循环回路边 + 循环体内公式 | `shapes.geometric` 的 `diamond`；`decorations` 标注 | "是/否"标签与循环边挤同一侧 | > 表里"模型结构机理图"是**机理图**；把训练集划分、层数超参、参数量当标注往上堆是**参数表**的活。

## 3. 图内数字的三条线（数据红线的落地版）

图里出现的每一个数字，必须落进下面某一格，落不进就改符号。**写不出来 = 不许出现。**

| 线 | 内容 | 判据 |
|---|---|---|
| 允许：**题面给定常量** | 螺距 55 cm、板长、初速、$k=10^4$、附表里的点位坐标 | 能在题目原文 / 题目分析报告 / 用户给的数据表里**指出出处** |
| 允许：**符号量** | $x^*$、$t^*$、$\theta_i$、$p_{\min}$、$\Delta\varphi$ | 表达"得到什么量"，不给具体值 |
| 允许：**图自身的几何量** | 画这条弧所需的半径、角度、比例（为构图取的相对值） | 属于图的数学内容，不是结论 |
| 禁止：**求解结果数值** | `t^*=412.473838`、`p_{\min}=45.03cm`、真实权重 0.317 | 只能待在结果表 / 数据图 / 正文（那里才有溯源闸），不许手敲进 `.tex` |
| 禁止：**编造的数据** | 任何"为了让图好看"造的点位、曲线数值、百分比 | 一律禁止，包括"合理假设值" | 材料缺失时（只有题目、没有分析报告/数据表）：**只画符号级机理图**，不猜任何数值；需要数值支撑的那张图改为在交付清单里写"缺材料，未画"，不要偷偷补。

## 4. 从材料到图的推导路径

不规定输入叫什么名字、放哪个目录——**给了什么就读什么**：论文（.tex/.docx/.pdf）、题目与题目分析报告、数据表格（.xlsx/.csv）、甚至对话里直接贴的一段话，都行。

要从中读出来的就 5 件事：

1. **有哪些模型/方法**（论文里逐个模型小节抓；只有题目时从"求解思路/假设"里抓）；
2. **每个模型的内核是哪一类**——几何关系？约束与最优？演化机制？结构？定了之后对第 2 节表选图型；
3. **题面给定了哪些常量与几何条件**（这些才能上图）；
4. **正文用的符号体系**（$S_i$、$w_j$、$\eta_i$…图里必须跟正文一致，别自造符号）；
5. **图的语种与篇幅位置**（中文/英文论文定 `MH_FIG_LANG`；一张图占半页还是整页决定 `scale`）。

一张图对应**一个**模型或**一个**关键几何/推导环节。宁少勿滥：一篇竞赛论文通常 2–4 张机理图就够（技术路线 1 张不属于本件）。

## 5. 交付形态

每张图三件套（`.tex`/`.pdf`/`.png`）+ 一份全图汇总，同名同目录：

```
<MH_OUT_DIR>/mech_<图名>.tex     % standalone 可独立编译的源码（交付主体）
<MH_OUT_DIR>/mech_<图名>.pdf     % 矢量，论文 \includegraphics 用
<MH_OUT_DIR>/mech_<图名>.png     % 位图，肉眼验收/预览用（MH_PNG_DPI）
<MH_OUT_DIR>/mech_includes.tex   % 汇总的 \begin{figure} 片段（含 \caption/\label 占位）
```

`.tex` 里**图内不许有标题**——标题走 LaTeX 的 `\caption{}`。
`includes.tex` 只追加、不覆盖别人写的 include；`keepaspectratio` 必带，`\label` 全文件唯一。
`.svg` 只在**纯英文图**（去掉 `ctex`）时才出得来，中文图交 `pdf`+`png`；实测细节见 `SKILL.md` 的 SVG 死路表。
