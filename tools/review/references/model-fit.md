# 模型适配性检查（本地改写版）

> 参考 BZD 模型字典的“适配性”思路，本地改写；不复制其模型库。

## 输入

- 题目任务；
- 数据结构：样本量、变量类型、时间/空间结构、缺失、重复测量、目标、约束；
- 候选模型与用途。

数据不足时只给临时判断，列出缺失证据；不编造分布/样本量。

## 八项检查

| 检查 | 问题 | 不合格后果 |
|---|---|---|
| 任务匹配 | 模型输出是否就是题目要的？ | 换模型或改输出 |
| 数据充分 | 样本量/变量/标签是否支撑？ | 降复杂度/换模型 |
| 假设成立 | 线性、独立、平稳、正态等是否成立？ | 检验/变换/换模型 |
| 依赖与泄漏 | 时间/空间/分组是否泄漏？ | 重划训练验证 |
| 输出对齐 | 输出粒度/单位/约束是否匹配？ | 调整目标/约束 |
| 验证可行 | 是否有基线、误差、残差、交叉验证？ | 补验证方案 |
| 可解释性 | 能否解释关键参数/阈值？ | 加解释或换模型 |
| 计算可行 | 规模/时间/内存是否可承受？ | 降规模/启发式 |

## 结论

- **合适**：八项均通过或有明确补救。
- **有条件合适**：存在可修复的前提（如补数据、改验证）。
- **不合适**：任务/数据/假设根本冲突。
- **证据不足**：缺关键数据或题目信息，待人工复核。

## 三问法（写进论文）

1. 为什么抽象成这个数学对象？
2. 为什么必须用这个模型？简单基线为什么不够？
3. 数据/假设/计算是否支撑这个复杂度？

三问答不清，模型选择维度（14 分）会明显丢分。

## 替代模型

不合适时给 2–4 个替代/配套模型，说明是替代、预处理、验证还是补充；不要只列模型名。
