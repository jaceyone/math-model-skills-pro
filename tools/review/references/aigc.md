# AIGC 与模型真实性风险（本地改写版）

> 只做风险提示，不做“AI 判定”，不指控学术不端；高风险项需人工复核。

## 语言层信号

| 信号 | 表现 | 处理 |
|---|---|---|
| 连接词模板化 | “综上所述/此外/进一步/显然”高频、间隔短 | 删冗余，换成具体逻辑 |
| 排比堆砌 | 三项以上同构句，无数据/来源 | 改成有数据的陈述 |
| 拔高词 | “显著提升/具有重要价值/充分证明”无基线 | 补数字/对比，或删 |
| 被动句密集 | 连续多句被动，执行者缺失 | 改主动，补主语 |
| 段落开头雷同 | 大量“根据/为了/利用”开头 | 变化句式，先给结论 |
| 文本过于规整 | 句长/段长/连接词高度一致 | 打散节奏，加入具体细节 |

## 模型层信号

| 信号 | 表现 | 处理 |
|---|---|---|
| 模型堆砌 | 一题套多个高级模型，无必要性 | 回到“为什么需要” |
| 伪改进 | 改了参数/模块，无消融/对比 | 补基线/消融，或删 |
| 伪检验 | 只写“误差较小/效果良好” | 给指标、阈值、对比 |
| 伪联动 | 前问输出没有真正进入后问 | 删“联动”表述或补接口 |
| 公式断裂 | 公式突然出现，符号未定义 | 补动机、符号、推导 |
| 结果不可追溯 | 数值只在正文出现，结果文件没有 | 写入 `results.json` |
| 引用不匹配 | 引用文献不支持该主张 | 换文献或删主张 |

## 风险等级

- **低**：个别措辞模板化，不影响主线。
- **中**：多处模板化/模型堆砌/检验薄弱，影响可信度。
- **高**：核心模型无必要性、结果不可追溯、引用与主张明显不匹配；需人工复核。

## 修改原则

1. 先修事实，再修语言。
2. 每段至少一个具体对象/数据/条件，不用空泛形容词。
3. 模型只保留能解释“为什么需要”的部分。
4. 检验必须有基线、指标、边界或扰动。
5. 不为了“像人写”而故意写错或加废话。

## 禁止

- 不根据文本特征直接判定“AI 生成”。
- 不把语言风格问题当作学术不端。
- 不编造“人工修改记录”。
